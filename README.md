# Learning-Sorting
This repository contains different type of sorting methods. A sorting algorithm helps to rearrange an array or list in  an order.

-- There exixts different types of sorting for different types of inputs.For example a binary array, a character array, an array with a large range of values or an array with many duplicates or a small vs large array.

-- The algorithm may also differ based on the output requirements.

-- These sorting functions typically are general purpose functions with flexibility of providing the expected sorting order (increasing or decreasing or by a specific key in case of objects)

-- In java,there is a built-in sort method- Arrays.sort() to sort array in T.C of O(nlogn), but also takes O(n) space. We use Collections.sort()-- to sort the specific list of collections in ascending order. It can also sort LinkedList and Queue as well.

## Sorting Algorithms:

### Comparison Based: 
   ```
     - Bubble sort 
     - Selection sort
     - Insertion sort
     - Merge sort
     - Quick sort
     - Heap sort 
     - Cycle sort

   ```

### Non Comparison Based:
  ```
     -  Counting Sort
     -  Radix sort
     -  Bucket sort
     -  Pigeonhole Sort

   ```
